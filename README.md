# Python Projects

This repository contains Python projects that I created to practice core programming concepts and improve my problem-solving skills.

---

## 1. Quiz Application

This is a console-based quiz program developed using Python. It asks multiple-choice questions and calculates the final score based on user input.

### Features

* Multiple-choice questions (A, B, C, D)
* Input validation
* Score calculation
* Menu-based interaction

### Concepts Used

* Conditional statements
* Loops
* Functions

---

## 2. Student Management System

This is a file-based application used to store and manage student records. The data is stored in a text file, which allows the program to save and retrieve information.

### Features

* Add new student
* View all students
* Search student by ID
* Delete student record

### Concepts Used

* File handling (`read`, `write`, `append`)
* Functions (modular programming)
* Loops and conditions
* Lists

---

## How to Run

Run the programs using:

```bash id="3e3a4k"
python quiz_app.py
```

# Quiz Application (Python)

This is a console-based Quiz Application built using Python.  
It allows users to answer multiple-choice questions and calculates the final score.

## Features
- Multiple-choice questions
- Input validation (accepts only A/B/C/D)
- Score tracking
- Menu-driven system

## Concepts Used
- Lists and indexing
- Functions
- Loops
- Conditional statements

## How to Run
1. Install Python
2. Run the program:
   python quiz_app.py
